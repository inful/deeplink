{{- /* Shortcode: deeplink-outlook-email Renders a mailto: link that opens the user's default mail client with a compose window pre-filled. Parameters (all named): to — REQUIRED. Recipient(s), comma-separated. cc — OPTIONAL. Carbon-copy recipient(s), comma-separated. bcc — OPTIONAL. Blind carbon-copy recipient(s), comma-separated. subject — OPTIONAL. Email subject body — OPTIONAL. Email body (plain text; newlines preserved) text — OPTIONAL. Link text class — OPTIONAL. CSS class target — OPTIONAL. Target attribute rel — OPTIONAL. Rel attribute Example: {{< deeplink-outlook-email to="alice@example.com" subject="Sprint planning" body="Agenda: ..." >}} NOTE: This template mirrors outlook.Email() in the Go library and produces the same URL. The to/cc/bcc values are written literally, because mailto: URLs carry their recipients as a comma-separated list rather than an encoded one. They are still rejected if they contain '&', '?', '#' or whitespace, because such a value could add parameters of its own — the same rule the Go library enforces. If you change one, change the other. */ -}} {{- $to := .Get "to" -}} {{- $cc := .Get "cc" -}} {{- $bcc := .Get "bcc" -}} {{- if and (not $to) (not $cc) (not $bcc) -}} {{- errorf "deeplink-outlook-email: at least one recipient is required (to, cc, or bcc)" -}} {{- end -}} {{- if findRE "[&?#[:space:]]" (printf "%s,%s,%s" $to $cc $bcc) -}} {{- errorf "deeplink-outlook-email: recipients must not contain '&', '?', '#' or whitespace" -}} {{- end -}} {{- $pairs := slice -}} {{- with .Get "subject" -}} {{- $pairs = $pairs | append (printf "subject=%s" (replace (urlquery .) "+" "%20")) -}} {{- end -}} {{- with .Get "body" -}} {{- $pairs = $pairs | append (printf "body=%s" (replace (urlquery .) "+" "%20")) -}} {{- end -}} {{- with $cc -}} {{- $pairs = $pairs | append (printf "cc=%s" .) -}} {{- end -}} {{- with $bcc -}} {{- $pairs = $pairs | append (printf "bcc=%s" .) -}} {{- end -}} {{- $query := delimit $pairs "&" -}} {{- $url := printf "mailto:%s" $to -}} {{- if $query -}}{{- $url = printf "%s?%s" $url $query -}}{{- end -}} {{- $text := or (.Get "text") (.Get "subject") "Compose email" -}} {{ $text }}
